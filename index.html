Cyber Security Micro-Project

Executive Summary

This project analyzes the deep intersection between computer memory performance hierarchies (Registers, L1-L3 Caches, DRAM, and Secondary Storage) and critical hardware-level cybersecurity vulnerabilities. As processing speeds increase, physical proximity and shared hardware structures introduce severe security risks.

Memory Tier & Security Matrix

Memory Tier Speed / Latency Primary Vulnerability
CPU Cache (L1-L3) < 10 ns (Volatile) Cache Timing Side-Channels (Spectre / Meltdown)
Main Memory (DRAM) 50 - 100 ns (Volatile) Rowhammer Bit-Flips & Cold Boot Scraping
Secondary Storage (SSD) Microseconds (Non-Volatile) Data Remnants & Unencrypted At-Rest Recovery
